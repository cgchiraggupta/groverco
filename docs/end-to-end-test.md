# Grover & Co. end-to-end test

Use clearly marked sample data so test submissions can be found and removed afterward. Do not enter real identity, bank or password information.

## 1. Test a free guide

1. Open [groverco.in](https://www.groverco.in/) and select **Access free resources**.
2. Enter a test name and phone number, select one guide, agree to contact about the request, and submit.
3. Confirm that the confirmation mentions email forwarding and that **Open your free guide** appears. Open it and use **Print / Save as PDF** if you want a printable copy.
4. Confirm the resource request appears in the admin dashboard and both inboxes receive its email alert.

## 2. Test creator and business matching

1. Select **Join as a creator**. Use a name beginning `TEST`, a working test email/phone you control, and sample details such as category `Food`, platform `Instagram`, location `Delhi`, and format `Reels`. Check the optional match-sharing box and submit.
2. Select **Business branding form**. Use a name beginning `TEST`, select the same category, platform, location and format, enter a sample campaign goal, check the optional match-sharing box and submit.
3. Sign in at [groverco.in/admin/](https://www.groverco.in/admin/) using the authorized Supabase administrator account.
4. Choose the test business in **Compare creators for a business request**. Confirm the test creator appears with four matching criteria.
5. Select **Prepare introduction draft**. It opens an unsent email draft to both test addresses with the opted-in profile and brief. Review it; nothing is sent until you send it from your email application.

## 3. Test a service enquiry and dashboard follow-up

1. Open a service group, choose a service, and submit a test enquiry with your own contact details and the contact-consent box checked.
2. Confirm it is saved in the admin panel and email alerts appear in the configured inboxes.
3. Change its follow-up status to **Reviewing** or **Contacted** and save.

## 4. Remove sample records

In the admin panel, find each `TEST` submission and use **Delete**. The dashboard asks for confirmation before permanent deletion. Email copies already delivered to inboxes remain there.

## Current setup notes

- Match suggestions require both sides to opt in and use exact matches on category, platform, location and content format.
- A proposed introduction stays an unsent draft for administrator review.
- Business contact-directory fields remain placeholders pending the details from the business owner.
