# Grover & Co website

Mobile-first, static Vite website. No backend, database, tracking, external fonts, or enquiry delivery is configured.

## Local use

- `npm ci`
- `npm run dev` (local development)
- `npm run build` (production output in `dist/`)
- `npm run preview` (review production output)

Deploy only `dist/`, not the repository root. It can be hosted on static hosting, including Hostinger or Vercel. No environment variables are needed. No DNS or hosting changes have been made.

## Source materials and content decisions

- Main wordmark “Grover & Co” is a provisional text treatment inferred from the folder/repository; no main-brand logo was supplied. The supplied creative logo says “Works by Nish”; headings follow the user's “Work by Nish”. Confirm final naming before launch.

Unclear source lines and private budget/schedule notes were not published. A practice index is used as the hero visual because no project photography/portfolio examples were supplied; the two logo assets are aligned to their own practices.
- No original handwritten references, additional brand document, portfolio, reference website URLs or photographs were present in the supplied project. The notes refer to originals not included. They remain content gaps.

## Enquiries

The brief tool is deliberately local-only. Required practice and a trimmed minimum 20-character brief are validated. It downloads a UTF-8 text file and explicitly says nothing was sent. Do not replace the confirmation with “sent” without a working, verified delivery service. No personal contact fields, cookies, localStorage or remote submission exist.
